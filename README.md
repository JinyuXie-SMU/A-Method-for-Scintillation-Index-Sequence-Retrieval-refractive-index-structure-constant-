1. code
(1) param_search_test.py: Automatically searches for hybrid_wd*.pth models, parses hyperparameters from filenames, tests all models obtained from the parameter search on param_search_train.py, and outputs detailed results for each model as well as a summary table.
(2) param_search_train.py: Trains 27 hyperparameter combinations (weight_decay, dropout, width), generating the corresponding hybrid models, training-history CSV files, loss and learning-rate curve PNGs, and saving the best model and experiment summary.
(3) test.py: Intended to compare three methods (spherical-wave Rytov hybrid, plane-wave Rytov hybrid, and pure DL) under two Rytov priors. The expected output is test_three_methods_two_priors.xlsx.
(4) train_plane_wave.py: Trains a plane-wave Rytov hybrid model (coefficient 1.23) and a pure DL baseline, saving them as plane_mixed.pth and pure_dl.pth, respectively. It also prints MAE, RMSE, and Log-Cosh for the three methods.
(5) train_spherical_wave.py: Trains a spherical-wave Rytov hybrid model (coefficient 0.496) and a pure DL baseline, saving them as spherical_mixed.pth and pure_dl.pth, respectively.
2. datasets
(1) SI.nb: A code that generates synthetic scintillation-index data based on the Rytov/von-Karman model. The formulas include Rytov variance, large-scale and small-scale log-amplitude variances, and scintillation index.
(2) test.xlsx: Test dataset in long-table format, containing columns for  , L, and scintillation index.
(3) train.xlsx: Training dataset in long-table format, containing columns for  , L, and scintillation index.
3. models
(1) plane_mixed.pth: Plane-wave Rytov hybrid model generated by train_plane_wave.py. It contains model parameters, scaler, window length, feature configuration, wavelength, k_factor, distances, Rytov mode, etc.
(2) pure_dl.pth: Pure deep-learning baseline model without a physical prior branch.
(3) spherical_mixed.pth: Spherical-wave Rytov hybrid model generated by train_spherical_wave.py.
